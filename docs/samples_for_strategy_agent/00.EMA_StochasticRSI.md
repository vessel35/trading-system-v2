# 하이킨아시 + EMA200 + Stochastic RSI 스캘핑 전략

> 출처: 유튜브 트레이딩 강의 트랜스크립트 (STT 자동 변환본)
> 정리일: 2026-08-06
> 상태: **원문 정리 완료 / 검증 필요 (백테스트 전)**

---

## 1. 한 줄 요약

200 EMA로 **방향을 고정**하고, Stochastic RSI 골든/데드크로스로 **타이밍**을 잡고,
하이킨아시 캔들의 **강한 몸통**으로 **트리거**를 확정한 뒤,
**손절 1.5% / 익절 3% (RR 1:2), 하루 최대 5회**로 기계적으로 반복하는 추세추종 전략.

핵심 주장은 "기법"이 아니라 **원칙 준수(감정 배제)** 에 있음.

---

## 2. 차트 세팅

| 항목 | 설정값 |
|---|---|
| 캔들 종류 | **Heikin Ashi** (하이킨아시) |
| 지표 1 | **EMA 200** (지수이동평균, 길이 200) |
| 지표 2 | **Stochastic RSI** |
| Stoch RSI 표시 설정 | 배경(Background) OFF / 상·하단 밴드 흰색 점선 / 미들라인 OFF |

**Stochastic RSI 구성 요소**

- **%K (파란선)**: 일정 기간 가격 범위 내 현재가의 백분율 위치. `< 20` 과매도 / `> 80` 과매수
- **%D (주황선)**: %K의 이동평균 (후행선)
- 판단 기준선: 20 / 80 (흰색 점선)

**하이킨아시 캔들 해석 (원문 근거)**

- 일반 캔들은 양·음봉이 번갈아 나와 추세 판단이 어려움 → HA는 평균값 기반이라 추세가 뭉쳐 보임
- **상승 신호**: 직전 캔들보다 몸통이 길고, **아랫꼬리가 없는** 깔끔한 양봉
- **하락 신호**: 직전 캔들보다 몸통이 길고, **윗꼬리가 없는** 깔끔한 음봉

## 3. 매매 규칙 (원문 그대로)

### STEP 1 — 방향 필터 (EMA 200)

- 가격이 **EMA200 위** → **롱만** 진입
- 가격이 **EMA200 아래** → **숏만** 진입
- 반대 방향 진입은 **절대 금지** (원칙)

### STEP 2 — 위치 확인

- 캔들이 EMA200 **근처로 되돌림**했을 때 (지지/저항 테스트 구간)

### STEP 3 — 신호 (Stoch RSI)

- 롱: %K(파랑)가 %D(주황)를 **상향 돌파**
- 숏: %K(파랑)가 %D(주황)를 **하향 돌파**

### STEP 4 — 트리거 (하이킨아시 캔들)

- 롱: 직전 봉보다 몸통이 길고 **아랫꼬리 없는 양봉** 마감 → 진입
- 숏: 직전 봉보다 몸통이 길고 **윗꼬리 없는 음봉** 마감 → 진입

### STEP 5 — 청산 (사전 예약 주문)

- **익절(TP): +3%**
- **손절(SL): -1.5%**
- 진입과 **동시에** TP/SL 주문을 미리 걸어둘 것
- 차트가 더 갈 것 같아도 **3%에서 무조건 익절**, 더 빠질 것 같아도 **1.5%에서 칼손절**

### STEP 6 — 횟수 제한

- **하루 최대 5회** (승패 무관, 5회 도달 시 종료)
- 이유: 연승 시 도파민 중독으로 인한 과매매 방지

## 4. 원문에서 강조된 리스크 관리 철학

- 어떤 매매법도 전쟁·팬데믹 같은 **외부 충격**에는 무력함 → 틀렸다고 판단되면 **즉시 손절**
- 합리화하며 버티다 대형 손실 또는 **청산**으로 이어짐
- 트레이딩은 **확률 싸움**, 반드시 지는 날이 옴
- 승률이 아무리 높아도 원칙 없는 매매는 **단 한 번의 패배로 전액 소실** 가능
- 이 기법을 안 쓰더라도 "**적정 손익비 + 거래 횟수 제한 + 원칙 준수**" 자체가 핵심

## 5. 원문의 오류·모순 정리 (STT 오인식 포함)

STT 변환 품질이 낮아 아래 표기가 섞여 있음. 실제 의미로 교정함.

| 원문(오인식) | 교정 |
|---|---|
| 하이키나시 | 하이킨아시 (Heikin Ashi) |
| 202M / 200일 지수 입형 | EMA 200 (200 지수이동평균) |
| 은봉 | 음봉 |
| 100분율 K / D | %K / %D |
| 매주 신호 | 매수 신호 |
| 쇼 포지션 | 숏 포지션 |
| 입절 | 익절 |
| 이전뽕 | 이전 봉 |
| 계절 | 계좌 |
| 청상 | 청산 |
| 트레이딩교 | 트레이딩뷰 (TradingView) |

**논리적 모순 2건**

1. **손익비 표기 불일치**
   - "손익비는 1.5 대 3" → 손절 1.5% : 익절 3% = **RR 1:2** (정확)
   - 후반부 "무조건 1.3으로 손익비를 맞춰라" → **1:2의 오인식**으로 판단. 1:3이라면 익절 4.5%여야 하므로 앞 규칙과 충돌.
   - **채택: RR 1:2 (SL 1.5% / TP 3%)**

2. **"EMA200 위/아래"와 "EMA200 근처 되돌림"의 시점 충돌**
   - 방향 필터는 종가 기준, 진입은 되돌림 기준 → 코드화 시 **"EMA200 위 + 가격이 EMA200으로부터 N% 이내"** 처럼 명시적 거리 조건 필요. 원문에는 N값이 없음.

## 6. "100회 매매로 $100 → $60,000" 주장 검증

원문 주장: 총 100회 매매로 100달러를 6만 달러(**640배**)로 만들 수 있다.

계산 결과 — **성립하지 않음.**

| 시나리오 | 100회 후 배수 |
|---|---|
| 100전 100승, 매회 +3% 복리 (레버리지 1배) | **19.2배** ($1,920) |
| 승률 50%, TP+3% / SL-1.5% 복리 | **2.06배** |
| 승률 45% | 1.65배 |
| 승률 40% | 1.32배 |

- 640배를 만들려면 **100전 100승 + 약 2.2배 레버리지**가 필요 → 현실성 없음
- **손익분기 승률 = 33.3%** (RR 1:2 기준). 수수료·슬리피지 포함 시 실질 **36~38%** 필요
- 승률 50% 가정 시 기대값 **+0.75%/거래** — 통계적으로는 양수 기댓값 전략이나, "폭발적 증가"는 마케팅 수사

> 결론: **규칙 자체(방향 필터 + RR 1:2 + 횟수 제한)는 합리적**이나, 수익률 주장은 과장. 백테스트로 실제 승률을 먼저 측정해야 함.

### 7.2 진입 조건 의사코드

```python
# 봉 마감 시점에만 평가 (intra-bar 진입 금지)
ha = heikin_ashi(ohlc)
ema200 = ema(ha.close, 200)     # source 선택은 7.4 참조
k, d = stoch_rsi(close, 14, 14, 3, 3)

trend_up   = ha.close[-1] > ema200[-1]
trend_down = ha.close[-1] < ema200[-1]

near_ema = abs(ha.close[-1] - ema200[-1]) / ema200[-1] <= EMA_PROXIMITY

cross_up   = k[-2] <= d[-2] and k[-1] > d[-1]
cross_down = k[-2] >= d[-2] and k[-1] < d[-1]

body      = abs(ha.close[-1] - ha.open[-1])
prev_body = abs(ha.close[-2] - ha.open[-2])
body_expanding = body > prev_body

bull_marubozu = (ha.close[-1] > ha.open[-1]
                 and (min(ha.open[-1], ha.close[-1]) - ha.low[-1]) <= body * WICK_TOL
                 and body_expanding)

bear_marubozu = (ha.close[-1] < ha.open[-1]
                 and (ha.high[-1] - max(ha.open[-1], ha.close[-1])) <= body * WICK_TOL
                 and body_expanding)

if trades_today < 5:
    if trend_up and near_ema and cross_up and bull_marubozu:
        open_long(entry=next_open, tp=+3%, sl=-1.5%)
    elif trend_down and near_ema and cross_down and bear_marubozu:
        open_short(entry=next_open, tp=+3%, sl=-1.5%)
```

### 7.3 청산 조건

- **TP/SL은 진입과 동시에 거래소에 OCO로 등록** (봇 다운 시에도 보호)
- 시간 기반 청산(time stop)은 원문에 없음 → 백테스트에서 추가 검토 권장
- 반대 신호 발생 시 조기 청산 여부: 원문에 없음 → **하지 않음(원칙 우선)** 을 기본값으로

### 7.4 ⚠️ 구현 시 최대 함정 — 하이킨아시 가격

**하이킨아시 종가는 실제 체결 가격이 아니라 평균값이다.**

- `HA_close = (O+H+L+C)/4`, `HA_open = (이전 HA_open + 이전 HA_close)/2`
- 백테스트에서 **HA 가격으로 진입/청산 체결을 계산하면 실제보다 훨씬 좋은 결과**가 나옴 (전형적인 과최적화 착시)
- **반드시**: 신호 판정은 HA, **체결가·TP·SL 계산은 실제 캔들(real OHLC)** 로 분리할 것
- TP 3% / SL 1.5%도 **실제 진입 체결가 기준**으로 계산
