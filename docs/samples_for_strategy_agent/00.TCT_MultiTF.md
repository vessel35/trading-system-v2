# TCT 전략 — 멀티 타임프레임 진입·청산 프레임워크 (연구/백테스트 설계서)

> **TCT = Trend(방향) · Context(위치) · Trigger(방아쇠)**
> 작성: 2026-08-06
> 성격: **제안 전략 + 검증 설계서.** 아직 검증되지 않은 가설이며, 아래 실험을 통과하기 전에는 실계좌에 투입하지 않는다.
> 선행 문서: `03. HA+EMA200+StochRSI`, `04. 엘리펀트(탄이샤) 구조매매`

---

## 0. 이 문서의 목적

"언제 사고 언제 파는가"를 **하나의 신호로 정하지 않고 세 개의 독립된 층으로 분해**한 뒤,
각 층이 실제로 성과에 기여하는지를 **개별적으로 측정 가능하게** 설계하는 것.

핵심 주장은 전략 자체가 아니라 **분해 방식**에 있다. 층을 분리해두면 실패했을 때 **어느 층이 틀렸는지 알 수 있고**, 통과했을 때 **어느 층이 수익의 원천인지 알 수 있다.** 03·04번 전략은 이게 불가능한 구조였다.

---

## 1. 왜 새로 설계하는가 — 03·04의 결함

| | 03. HA+EMA200+StochRSI | 04. 엘리펀트 구조매매 |
|---|---|---|
| 방향 판단 | EMA200 위/아래 **단일 조건** | **없음** |
| 위치 판단 | EMA200 근처 (거리 기준 미정의) | 방향 전환 구간 (우수) |
| 트리거 | StochRSI 크로스 + HA 마루보즈 | 장악형/긴꼬리 (우수) |
| 손절 | 고정 1.5% (**구조 무시**) | 진입봉 극단 (구조적, 우수) |
| 익절 | 고정 3% (**추세 포기**) | 반대 구간 (**가변, 관리 난이도**) |
| 리스크 관리 | 일 5회 상한 (우수) | **없음** |
| 치명적 결함 | **횡보장 구분 못 함** → EMA200 근처는 휩쏘가 가장 심한 자리 | **Repaint / 리스크 규칙 부재** |

**두 전략의 공통 맹점: 시장 상태(Regime)를 구분하지 않는다.**

- 03번은 추세추종인데 횡보장에서도 그대로 돈다. EMA200 근처 되돌림 진입은 **횡보장에서 최악**이다.
- 04번은 역추세인데 강한 추세장에서도 그대로 돈다. 추세장에서 구간 역추세는 **칼날 잡기**다.

두 전략 모두 **잘못된 장세에서 정확히 반대로 작동**한다. 이게 TCT의 출발점이다.

## 2. TCT 구조 — 3층 분해

```
┌─────────────────────────────────────────────┐
│  Layer 1 · TREND   (4H)   — 어느 방향만 볼 것인가  │
│    시장 상태 분류 → 플레이북 선택                  │
├─────────────────────────────────────────────┤
│  Layer 2 · CONTEXT (4H존 + 15m) — 어디서 볼 것인가 │
│    가격이 의미 있는 자리에 왔는가                  │
├─────────────────────────────────────────────┤
│  Layer 3 · TRIGGER (15m)  — 정확히 언제 누를 것인가 │
│    반전 확정 캔들 마감                            │
└─────────────────────────────────────────────┘
        세 층이 모두 정렬될 때만 진입
```

**설계 원칙 — "하락을 사는" 조건**

> 하락을 매수한다 = **상승 추세 안의 되돌림**에서만.
> 하락 추세에서의 저가 매수는 **금지**한다.
> 상승을 매도한다 = **하락 추세 안의 반등**에서만.
> 상승 추세에서의 고가 매도는 **금지**한다.

역추세 양방향 매매는 **Range 판정이 났을 때만** 허용한다. (이것도 H5에서 검증 대상)

### Layer 1 — TREND (4H): 시장 상태 분류

4H 봉 마감 시점에 시장을 **세 상태 중 하나**로 분류한다.

| 상태 | 조건 | 플레이북 |
|---|---|---|
| **Trend-Up** | `close > EMA200` **AND** `EMA200 기울기 > 0` **AND** `ADX(14) ≥ 20` | **롱만** — 지지 구간 되돌림 매수 |
| **Trend-Down** | `close < EMA200` **AND** `EMA200 기울기 < 0` **AND** `ADX(14) ≥ 20` | **숏만** — 저항 구간 반등 매도 |
| **Range** | `ADX(14) < 20` | 구간 양방향 역추세 **또는 휴식** (H5에서 결정) |

- EMA200 기울기: `(EMA200[0] - EMA200[-20]) / EMA200[-20]`, 임계값 `TODO`
- ADX 임계값 20은 관례값 — **그리드 서치 대상** (15/20/25)
- 상태 전환 시 **기존 포지션은 유지**, 신규 진입만 차단 (H6에서 검증)

> 이 층이 03번의 "EMA200 위/아래" 단일 조건을 대체한다. 추가된 것은 **기울기(추세의 존재)** 와 **ADX(추세의 강도)** 두 가지다.

### Layer 2 — CONTEXT (4H 구간 + 15m): 위치 판단

04번의 **방향 전환 구간(Zone)** 을 그대로 채택하되, **4H에서 탐지**한다.

**구간 정의**

- 4H 스윙 고점/저점을 만든 **직전 마지막 반대색 캔들**의 `low ~ high` 전체
- `mid = (low + high) / 2`
- 지지 구간(초록) / 저항 구간(빨강)
- **★ `confirmed_at = pivot_index + lookback`** — 이 시점 이후에만 사용 가능 (Repaint 방지)

**진입 허용 위치**

| 상태 | 허용 위치 |
|---|---|
| Trend-Up | 가격이 **4H 지지 구간** 또는 **EMA200(4H) ± ATR** 영역까지 되돌림 |
| Trend-Down | 가격이 **4H 저항 구간** 또는 **EMA200(4H) ± ATR** 영역까지 반등 |
| Range | 구간 경계 (양방향) |

**구간 등급 (사전 판정 가능한 것만)**

04번의 "이 구간은 중요하고 저 구간은 아니다"는 사후 판단이었다. 실시간에 쓸 수 있는 대체 기준:

| 등급 요소 | 측정 |
|---|---|
| 생성 시 거래량 | 구간 캔들 거래량 / 최근 20봉 평균 |
| 임펄스 크기 | 전환 이후 이동폭 / ATR |
| 미터치 여부 | 아직 한 번도 되돌아오지 않은 구간이 더 강함 |
| 상위 구조 일치 | 1D 구간과 겹치는가 |

등급 하위 구간은 진입 후보에서 제외. 임계값 `TODO`, **H4에서 검증**.

### Layer 4 — 리스크·청산

여기가 03·04를 모두 개선하는 지점이다.

**손절 — 고정 %가 아니라 구조 기반**

```
롱:  SL = min(트리거 캔들 저점, 진입 구간 하단) - 0.5 × ATR(15m)
숏:  SL = max(트리거 캔들 고점, 진입 구간 상단) + 0.5 × ATR(15m)
```

- 03번의 고정 1.5%는 **변동성을 무시**한다. 저변동 구간에서는 너무 넓고, 고변동 구간에서는 너무 좁다.
- ATR 버퍼는 **스톱헌팅 방어**용. 계수 0.5는 `TODO`, 그리드 서치.

**포지션 사이즈 — 손절 거리에서 역산**

```
수량 = (계좌 × 거래당리스크%) / |진입가 - SL|
```

- **거래당 리스크 0.5%** 를 기본값으로 제안 (근거는 §5.3)
- 이렇게 하면 손절폭이 얼마든 **1회 손실은 항상 계좌의 0.5%** 로 고정된다 = 1R
- 레버리지는 결과값일 뿐 입력값이 아니다

**최소 RR 필터 — 진입 스킵 조건**

```
다음 반대 구간까지 거리 ÷ 손절 거리 < 1.5  →  진입하지 않는다
```

04번의 가장 큰 실무 문제(가변 RR)를 여기서 해결한다. **목표가 손절보다 가깝거나 비슷하면 아예 안 친다.**

**익절 — 부분 익절 + 구조 트레일링**

| 단계 | 조건 | 행동 |
|---|---|---|
| TP1 | **+1R 도달** | **50% 청산**, 나머지 SL을 **본전(BE)** 으로 이동 |
| TP2 | 반대 구간 **근단선 도달 + 반전 신호** | 잔량 전량 청산 |
| 트레일 | TP1 이후 | 15m 스윙 저점(롱)/고점(숏) 아래 0.5ATR 추적 |
| 조기 청산 A | 구간 진입 후 **중간선 미돌파 + 반전 신호** | 전량 청산 *(04번 규칙)* |
| 조기 청산 B | 구간 **내부**에서 반대 신호 1회 | 전량 청산 *(04번 규칙)* |
| 시간 청산 | `N`봉 경과 후 +0.3R 미만 | 전량 청산 (`N` = `TODO`) |

- TP1 부분익절 + BE 이동은 **승률을 인위적으로 끌어올리고 심리 부담을 줄이는** 대신 평균 R을 깎는다. **H7에서 순효과를 측정**한다. 넣는 게 당연하다고 가정하지 않는다.

**리스크 상한 (전부 하드 스톱)**

| 항목 | 값 |
|---|---|
| 거래당 리스크 | 0.5% (1R) |
| 동시 보유 포지션 | 1개 |
| 일일 손실 한도 | **-2R** 도달 시 당일 중단 |
| 주간 손실 한도 | **-5R** 도달 시 주간 중단 |
| 연패 서킷브레이커 | **6연패** 시 중단 → 수동 리뷰 후 재개 |
| 상관 자산 | BTC/ETH 동시 진입 금지 (사실상 같은 포지션) |

## 3. 완전한 진입 체크리스트

**롱 (하락을 매수)**

```
[ ] 1. 4H 상태 = Trend-Up
       close > EMA200 & EMA200 기울기 > 0 & ADX ≥ 20
[ ] 2. 가격이 4H 지지 구간 또는 EMA200±ATR 로 되돌림
[ ] 3. 해당 구간 등급 = 상위 (거래량/임펄스/미터치)
[ ] 4. 15m 상승장악형 또는 해머, body ≥ 1.0 ATR, 봉 마감 확정
[ ] 5. SL = min(트리거저점, 구간하단) - 0.5ATR
[ ] 6. (다음 저항구간까지 거리 / SL거리) ≥ 1.5
[ ] 7. 오늘 손실 < 2R, 연패 < 6, 보유 포지션 없음
       → 전부 충족 시에만 진입
```

**숏 (상승을 매도)** — 위 조건의 완전 대칭

**절대 금지**

- Trend-Down에서 지지 구간 롱 (하락 추세 저가 매수)
- Trend-Up에서 저항 구간 숏 (상승 추세 고가 매도)
- 구간 **내부**에서의 신규 진입 (혼전 구역)
- 봉 마감 전 진입

## 4. 검증 가설 (H1~H8)

**이 문서의 본체.** 각 가설은 독립적으로 측정하고, 실패하면 해당 층을 버린다.

| # | 가설 | 검증 방법 | 통과 기준 |
|---|---|---|---|
| **H1** | 진입 트리거(반전 캔들)만으로도 무작위보다 낫다 | Layer 3 단독 — 방향·위치 필터 없이 전 구간 진입, 고정 1R/2R 청산 | 기대값 > 0R |
| **H2** | **Regime 필터(Layer 1)가 성과를 개선한다** | H1 baseline에 Layer 1만 추가 | **기대값 +0.1R 이상 개선** |
| **H3** | StochRSI 확인 조건이 기여한다 | on/off ablation | 미개선 시 **제거** |
| **H4** | 구간 등급 필터가 기여한다 | 등급 필터 on/off | 미개선 시 **제거** |
| **H5** | Range 구간에서 역추세 매매가 유효하다 | Range 거래만 분리 집계 vs 휴식 | 기대값 ≤ 0이면 **Range = 휴식** |
| **H6** | 구조 기반 SL이 고정 % SL보다 낫다 | 구조SL vs 고정1.5% 비교 | 기대값·MDD 동시 개선 |
| **H7** | TP1 부분익절 + BE 이동의 순효과가 양수다 | on/off ablation | 기대값 감소 시 **제거** (승률만 오르고 손해) |
| **H8** | 멀티TF가 단일TF보다 낫다 | 4H+15m vs 15m 단독 | 기대값 개선 |

**핵심은 H2다.** §2에서 진단한 "두 전략의 공통 맹점"이 사실인지 여기서 판가름 난다. H2가 실패하면 TCT의 전제 자체가 틀린 것이므로 **설계를 원점에서 재검토**한다.

**실험 순서 (반드시 이 순서)**

```
Step 0  데이터 구축 + 편향 점검
Step 1  H1 baseline
Step 2  H2 (Layer 1 추가)        ← 여기서 실패하면 중단
Step 3  H6 (SL 방식)
Step 4  H8 (멀티TF)
Step 5  H3 / H4 / H7 ablation    ← 기여 없는 층 제거
Step 6  H5 (Range 처리 결정)
Step 7  파라미터 그리드 서치      ← 반드시 마지막
Step 8  Walk-forward 검증
Step 9  페이퍼 트레이딩
```

> **파라미터 튜닝을 먼저 하지 않는다.** 구조를 먼저 확정하고 튜닝은 맨 마지막에. 순서를 바꾸면 과최적화된 숫자에 구조를 끼워 맞추게 된다.

## 5. 통계 설계

### 5.1 필요 표본 수

멀티TF 구조상 하루 1~3회 → 연 250~750거래. 2년 데이터로 500~1500 표본 확보 가능.

승률 45% 가정 시 표본별 정밀도:

| 표본 수 | 승률 표준오차 | 95% 신뢰구간 |
|---|---|---|
| 100 | 4.97%p | ±9.75%p |
| 250 | 3.15%p | ±6.17%p |
| **500** | **2.22%p** | **±4.36%p** |
| 1000 | 1.57%p | ±3.08%p |

**최소 300거래, 권장 500거래 이상**에서만 결론을 낸다.
100거래로 "승률 50% 나왔다"는 실제로는 40~60% 어딘가라는 뜻이므로 **아무 정보가 없는 것과 같다.**

### 5.2 평가 지표 — 승률은 보지 않는다

| 지표 | 정의 | 목표 |
|---|---|---|
| **기대값(Expectancy)** | 거래당 평균 R | **> +0.15R** |
| Profit Factor | 총이익 / 총손실 | > 1.3 |
| MDD | 최대 낙폭 | < 15% |
| **R-multiple 분포** | 히스토그램 | 소수 대박 의존 여부 확인 |
| 최대 연패 | — | 서킷브레이커 설정 근거 |
| 몬테카를로 파산확률 | 거래 순서 무작위 재배열 1만회 | -20% 도달 확률 < 5% |
| 손익분기 승률 | 1/(1+평균R) | 실측 승률과 마진 확인 |

**손익분기 승률** — 평균 승리 1.8R / 패배 -1R 가정 시 **35.7%**

| 실측 승률 | 거래당 기대값 |
|---|---|
| 35% | -0.02R (손실) |
| 40% | +0.12R |
| **45%** | **+0.26R** |
| 50% | +0.40R |

### 5.3 리스크 0.5%의 근거

승률 45%, 500거래 기준 최대 연패 분포 (10,000회 시뮬레이션):

| | 연패 |
|---|---|
| 중앙값 | **9회** |
| 90 percentile | **12회** |
| 99 percentile | **16회** |
| 최악 | 30회 |

**연 500거래를 돌리면 9연패는 반드시 온다.** 12연패도 10% 확률로 온다.

- 리스크 2%였다면 12연패 = **-24%** → 심리적으로 봇을 끄게 된다
- 리스크 0.5%면 12연패 = **-6%** → 견딜 수 있다

연간 시뮬레이션 (리스크 0.5%, 500거래, 승 1.8R / 패 -1R):

| 승률 | 연 수익률 중앙값 | 하위 5% | MDD 중앙값 | MDD 95%tile |
|---|---|---|---|---|
| 40% | +33% | +5% | 9.2% | 16.2% |
| **45%** | **+92%** | +47% | 6.5% | 10.3% |
| 50% | +168% | +112% | 4.9% | 7.6% |

> 03번 영상의 "100회에 640배"와 비교할 것. **현실적인 좋은 전략은 연 30~90%다.**
> 그리고 위 숫자조차 승률 45%가 실측으로 확인된 뒤에야 의미가 있다.

## 6. 편향 방지 체크리스트 (Step 0)

이 단계를 건너뛰면 이후 모든 숫자가 무의미하다.

| # | 편향 | 방지 |
|---|---|---|
| 1 | **Repaint / Look-ahead** | 구간은 `confirmed_at` 이후에만 사용. **지연 있는 버전 / 없는 버전 성과를 반드시 비교** — 차이가 크면 미래를 보고 있다는 증거 |
| 2 | 멀티TF 정렬 오류 | 4H 값은 **해당 4H 봉이 마감된 이후**의 15m 봉에만 적용. 4H 진행 중 값 사용 금지 |
| 3 | Intra-bar 체결 | 진입·청산 모두 **봉 마감가** 기준. 같은 봉에서 TP·SL 동시 터치 시 **SL 우선**(보수적) |
| 4 | 수수료·슬리피지 | 왕복 0.08% + 슬리피지 0.02% 반영. **필수** |
| 5 | 펀딩비 | 정산 시각(00/08/16 UTC) 보유분 반영 |
| 6 | 과최적화 | 파라미터는 Step 7에서만. 조합 수 기록하고 **최고값이 아니라 안정 고원(plateau)** 을 선택 |
| 7 | 표본 부족 | 300거래 미만 결과로 결론 금지 |
| 8 | 단일 종목 | BTC 외 ETH/SOL 최소 2종 추가 검증 |
| 9 | 단일 장세 | 2021 상승 / 2022 하락 / 2023 횡보 **분리 집계** |

**Walk-forward 설계**

```
학습 6개월 → 검증 2개월, 2개월씩 롤링
전체 구간: 최소 2년, 권장 3년
OOS 성과가 IS의 50% 미만이면 과최적화로 판정 → 파라미터 축소
```

## 8. 폐기 기준 (Kill Criteria)

**사전에 정해둔다.** 나중에 정하면 결과를 보고 기준을 옮기게 된다.

| 조건 | 판정 |
|---|---|
| H2 실패 (Regime 필터 미개선) | **설계 전제 오류** → 원점 재검토 |
| 500거래 기준 기대값 < +0.05R | **폐기** |
| OOS 기대값이 IS의 50% 미만 | 과최적화 → 파라미터 축소 후 재검증, 2회 실패 시 폐기 |
| Repaint 유무 성과차 > 30% | 구간 로직 결함 → 재구현 |
| MDD > 25% | 리스크 재설계 |
| 3개 장세 중 2개에서 기대값 음수 | 범용성 없음 → 특정 장세 전용으로 격하 |
| 페이퍼 4주 기대값이 백테스트의 50% 미만 | 실행 갭 → 원인 규명 전까지 실계좌 금지 |

## 9. 이 전략에 대한 정직한 평가

**강점**

- 층 분리로 **실패 원인 추적이 가능**하다. 03·04는 불가능했다.
- 리스크가 R 단위로 통일되어 **손절폭과 무관하게 손실이 일정**하다.
- 구조 기반 SL + 최소 RR 필터로 **나쁜 자리를 자동으로 거른다**.
- 검증 순서와 폐기 기준이 사전에 고정되어 **결과에 맞춰 기준을 바꿀 여지가 없다**.

**약점 / 미검증**

- **아직 아무것도 검증되지 않았다.** 이건 가설이지 전략이 아니다.
- 조건이 많아 **진입 빈도가 낮을 수 있다.** 표본 확보에 시간이 걸린다.
- Layer 2의 구간 등급은 여전히 **임계값 근거가 약하다.** H4에서 기여가 없으면 버려야 한다.
- 4H+15m 조합 자체가 **최적이라는 근거가 없다.** H8이 그걸 묻는 것이다.
- 암호화폐는 **뉴스·규제 충격에 구조가 무의미해지는 구간**이 있다. 이 전략은 그걸 다루지 않는다 — 별도의 킬스위치가 필요하다.

**한 줄 결론**

> TCT는 "더 좋은 매매법"이 아니라 **"무엇이 좋은지 알아낼 수 있는 구조"** 다.
> 03·04를 각각 백테스트하는 것보다, TCT의 H1→H2 순서로 검증하면
> **두 전략의 어느 부분이 실제로 작동하는지를 같은 실험 안에서 알 수 있다.**
